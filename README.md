# 🧹 JSON Pretty Printer

A lightweight Python CLI tool that converts compact or messy JSON into clean, readable JSON.

## Features

- Format JSON automatically
- Validate JSON syntax
- Preserve Unicode characters
- Simple command-line interface
- No external dependencies

## Run

```bash
python main.py
```

## Example

Input:

```json
{"name":"Aliya","skills":["Python","UI/UX"],"active":true}
```

Output:

```json
{
    "name": "Aliya",
    "skills": [
        "Python",
        "UI/UX"
    ],
    "active": true
}
```
